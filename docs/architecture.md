# 架构说明

## 概述

本系统实现 CI/CD 驱动的自动化操作系统补丁管理，通过分阶段审批流程控制补丁从开发环境到预发布环境的逐步部署，并在每次部署前创建镜像备份。

## 数据流

1. **源码变更**：开发者提交补丁配置变更到代码仓库
2. **触发流水线**：CodeArts Pipeline 检测到代码变更，启动流水线
3. **审批门禁**：流水线在每个环境前设置人工审批步骤
4. **构建执行**：审批通过后，CodeArts Build 执行 `patch_automation.py`
5. **实例查询**：脚本按标签查询目标 ECS 实例
6. **镜像备份**：为每个实例创建 IMS 镜像备份
7. **补丁执行**：通过 FunctionGraph 函数在实例上执行补丁命令
8. **结果通知**：通过 SMN 发送执行结果通知
9. **黄金镜像**：补丁验证通过后，创建新的黄金镜像供后续部署使用

## 安全设计

- OBS 桶使用私有 ACL + 服务端加密
- FunctionGraph 通过 IAM 委托获取最小权限
- 安全组仅允许 VPC 内网 SSH 访问
- SMN 通知不包含敏感信息
- AK/SK 通过环境变量传递，不硬编码在代码中
